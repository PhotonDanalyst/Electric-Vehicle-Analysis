## 🎯 Project Goal
The primary objective was to build a comprehensive analytical tool to visualize and track the rapidly evolving U.S. electric vehicle market. The dashboard provides strategic insights for stakeholders (e.g., manufacturers, charging infrastructure providers) to forecast adoption, assess regional performance, and inform policy.

## 📊 Key Metrics & Insights
* **Total Market Size:** Tracks total registered vehicles (currently **150.42K**), segmented by Battery Electric Vehicles (**BEV - 78%**) and Plug-in Hybrid Electric Vehicles (**PHEV - 22%**).
* **Adoption Trends:** Visualizes vehicle counts by model year, highlighting key periods of market acceleration.
* **Geographic Distribution:** State-level mapping to show regional EV density and market saturation.
* **Competitive Analysis:** Detailed breakdown of vehicles by manufacturer (Make) and specific Model (e.g., Tesla, Nissan, Chevrolet).
* **Range Analysis:** Includes metrics such as Average Electric Range (**67.83Km**).

## 🛠️ Technologies & Tools Used
* **Data Sourcing/Processing:** Python (Pandas for data cleaning and preparation).
* **Visualization & Dashboarding:** Microsoft Power BI (for creating the interactive and dynamic report).
* **Geospatial Analysis:** Power BI's built-in map visuals for state-level data representation.
